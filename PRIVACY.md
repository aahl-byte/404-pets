# Privacy Policy — 404 Pets

_Last updated: 2026-07-08_

404 Pets is a browser extension that displays a decorative animated pixel cat on
web pages. This policy explains what the extension does and does not do with
your data.

## What we collect

**Nothing.** 404 Pets does not collect, store, or transmit any personal
information, browsing history, or page content.

## Data the extension stores

The extension saves only your own settings using the browser's
`chrome.storage.sync` API:

- whether the pet is enabled or disabled
- the selected coat color

This data stays within your browser (and syncs across your own signed-in Chrome
instances through Google's built-in sync). It is never sent to us or any third
party. We operate no servers and have no access to it.

## Host permissions

The extension runs on all sites (`<all_urls>`) so the cat can appear on whatever
page you are viewing. Its content script only draws a decorative overlay and
reads on-page element positions so the cat can climb page elements. It does not
read, record, or transmit the contents of the pages you visit.

## Remote code

The extension contains no remote code. All behavior ships inside the extension
package; it loads no external scripts and makes no network requests.

## Third parties

None. No analytics, no advertising, no trackers.

## Changes

If this policy changes, the updated version will be published in the extension's
repository with a new "Last updated" date.
